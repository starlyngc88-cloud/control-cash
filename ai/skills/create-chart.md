# Create Chart Skill

Para crear gráficos en KellyCash:
- Usar barras horizontales con divs (no librerías externas)
- Ancho de barra: style={{ width: ${porcentaje}% }}
- Colores semánticos: green (ingresos/diferencia positiva), red (gastos/exceso)
- Tooltips con texto simple (no librerías)
- Responsive: width full en mobile
