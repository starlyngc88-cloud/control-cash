# Create Dashboard Skill

Para crear dashboards:
- Header con ícono + título + filtro de fechas (DateFilter component)
- Grid de cards con métricas clave
- Barra de progreso con div (altura h-1.5 o h-2.5)
- Lista de últimos movimientos unificada
- Usar useMonthFilter() para filtro compartido
- Cargar datos con useEffect + useCallback
